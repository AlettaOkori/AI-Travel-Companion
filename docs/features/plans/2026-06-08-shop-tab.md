# 商城 Tab 实施计划

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 Harvest Tab 中新增「商城」inner tab，展示开平碉楼文创商品，支持浏览、加购、结算完整流程。

**Architecture:** 单页浮层式。商城页为单一滚动页面，商品详情/结算用全屏浮层，购物车用底部抽屉。数据内联在 app.html 中，购物车状态持久化到 localStorage。

**Tech Stack:** 纯 HTML + CSS + JS（无框架），延续现有 app.html 内联风格。

## Task 5: 实现商城渲染函数

**Files:** Modify `app.html`

### 5.1 `renderHarvestShop()`
挂载到 `renderHarvest()` 中，渲染整个商城页：

```js
function renderHarvestShop() {
  const el = document.getElementById('harvest-shop');
  if (!el) return;
  el.innerHTML = renderShop(window.currentShopSpot);
}
```

### 5.2 `renderShop(spotId)`
返回完整商城 HTML 字符串：
- 景点切换栏
- Banner
- 筛选排序栏
- 商品网格
- 底部购物车栏

### 5.3 `renderShopGrid(spotId, filter, sort)`
根据筛选和排序条件渲染商品网格。

排序逻辑：
- `综合`：默认顺序
- `销量`：按 sales 降序
- `价格`：按 price 升序/降序（切换）

## Task 6: 实现详情浮层、购物车抽屉、结算浮层

**Files:** Modify `app.html`

### 6.1 `openShopDetail(productId)`
打开商品详情浮层（全屏 overlay）。

### 6.2 `addToCart(productId, qty)`
添加商品到购物车，更新角标，持久化 localStorage，toast 提示。

### 6.3 `openCart()`
打开购物车抽屉（从底部滑出）。

### 6.4 `updateCartQty(productId, delta)`
增减购物车商品数量，数量为 0 时移除。

### 6.5 `goCheckout()`
从购物车进入结算浮层。

### 6.6 `submitOrder()`
提交订单，toast 成功，清空购物车，关闭浮层。

## Task 8: 验证测试

**验证步骤：**
1. 打开 `app.html` → 切换到「行后」→ 点击「商城」tab
2. 验证：景点切换栏、banner、筛选栏、商品网格、底部购物车栏均正常显示
3. 点击商品卡片 → 详情浮层弹出
4. 点击「加入购物车」→ toast 提示，底部角标更新
5. 点击底部购物车 → 抽屉展开，显示商品和数量
6. 点击「去结算」→ 结算浮层弹出
7. 点击「确认购买」→ toast 成功，购物车清空
8. 点击景点切换（非开平碉楼）→ toast 提示「开发中」
